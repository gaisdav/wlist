Этот каталог содержит **универсальное, подробное и готовое руководство по архитектуре** для создания масштабируемых цифровых экосистем. Шаблон основан на современных проверенных практиках разработки кросс-платформенных приложений.

## 2. Инструкция по адаптации шаблона для нового проекта

Все примеры кода и конфигураций в этих файлах намеренно используют универсальный префикс бренда **`@brand`** (например, `@brand/core`, `@brand/api`, `@brand/config`, `--brand-theme-bg` и т.д.).

Чтобы сделать эту документацию персональной для вашего нового проекта:

1.  **Скопируйте папку** `architecture-template/` в корень нового проекта.
2.  Выполните **глобальный поиск и замену (Case Sensitive)** в вашей IDE по скопированной папке:
    - Замените `@brand/` на имя вашего пакета (например, `@wishlist/`, `@my-app/`).
    - Замените `brand-theme` на имя вашего префикса CSS-переменных (например, `wlist-theme`).
    - Замените `brand` (в текстовых описаниях) на название вашего продукта.
3.  Отредактируйте таблицы баз данных и примеры в документах `02. Слой данных` и `03. Бизнес-логика`, заменив демонстрационные сущности (`items`, `itemsService`) на ключевые сущности вашей предметной области (например, `wishes`, `orders`, `profiles`).
