# Этап 10. Полноценный Telegram-бот: уведомления и секретные чаты

## Цель

Развернуть Telegram-бота из «launcher Mini App» в полноценный канал коммуникации: уведомления о бронировании, напоминания о событиях и автоматическое создание секретных групповых чатов для скинувшихся участников.

## Зависимости

- Этап 03 (слоты) — для уведомлений по слотам.
- Этап 06 (комментарии) — для уведомлений об упоминаниях.
- Этап 07 (события) — для напоминаний о праздниках.

## Скоуп

### 1. Бэкенд бота

- Выделить отдельный сервис: либо Edge Function на Supabase + webhook от Telegram, либо отдельный long-running worker (если ограничения Edge Functions станут узким местом).
- Сохранять `chat_id` пользователя в `profiles.tg_private_chat_id` (получаем при первом /start).
- Очередь исходящих сообщений (например, через Postgres-таблицу `outbox` + воркер с retry).

### 2. Виды уведомлений

| Триггер                                                  | Получатель                          | Текст (примерно)                                                     |
| -------------------------------------------------------- | ----------------------------------- | -------------------------------------------------------------------- |
| Кто-то забронировал слот моего совместного желания (нет, скрыто) | —                                   | (не отправляем — нарушает приватность)                               |
| Слот, который ты забронировал, освободился у кого-то ещё | держатели активных слотов           | «У @Маши освободилось место в желании «AirPods». Можешь занять.»     |
| Желание полностью собрано                                | держатели слотов                    | «Желание @Маши «AirPods» собрано — пора покупать.»                   |
| Через 2 недели — день рождения друга                     | подписчики                          | «Через 2 недели у @Маши день рождения. Её вишлист: …»                |
| Тебя упомянули в комментарии                             | упомянутый                          | «@Вася упомянул тебя в обсуждении желания «AirPods».»                |
| Новый подписчик                                          | автор                               | «@Петя подписался на тебя.»                                          |

Каждое уведомление можно отключить в настройках профиля.

### 3. Настройки уведомлений

Таблица `public.notification_settings`:

- `user_id` (PK)
- `slot_freed` (`bool`, default true)
- `wish_collected` (`bool`, default true)
- `event_reminder` (`bool`, default true)
- `mention` (`bool`, default true)
- `new_follower` (`bool`, default true)

UI: отдельный экран «Уведомления» в профиле.

### 4. Секретные групповые чаты

> Сложная фича — требует уточнения возможностей Telegram Bot API.

- Когда **все слоты** желания заняты (или по запросу одного из участников) — бот предлагает создать групповой чат.
- Реализация:
  - Бот создаёт чат через `createChat` (если доступно для бота) — **на 2024–2026 у официального Bot API нет создания групп напрямую**, только присоединение.
  - **Альтернатива:** генерируем `t.me/+<invite_link>` через предсозданный «бот-чат» или используем UserBot (рискованно для прода).
  - **Реалистичный вариант:** один из участников создаёт групповой чат вручную → добавляет бота → бот регистрирует `chat_id` за желанием → дальше бот рассылает обновления.
- Сохранить `wishes.tg_chat_id` (поле уже добавили в этапе 06).

### 5. Команды бота

- `/start` — приветствие, кнопка «Открыть Mini App».
- `/start <payload>` — deep-link, открывает Mini App на нужном экране.
- `/notifications` — настройки.
- `/help`.

### 6. Аналитика и мониторинг

- Логировать доставку каждого исходящего сообщения.
- Алерты при росте 4xx/5xx от Telegram API.
- Sentry на webhook-ошибки.

## Вне скоупа

- AI-ассистент в чате (этап 13 / backlog).
- Автоматическая модерация общих чатов.

## Ключевые решения

- **Outbox + воркер**, а не прямые отправки из триггеров — иначе любой сбой в Telegram API сломает основной запрос пользователя.
- **Уведомления по умолчанию включены, но легко выключаются** — иначе спам разрушит UX.
- **Групповые чаты — как фича «по запросу»**, не автоматически. Проще и юридически чище.

## Definition of Done

- Все типы уведомлений рассылаются и логируются.
- Пользователь может выключить любой тип в настройках.
- Бот корректно обрабатывает deep-link `start payload`.
- Групповой чат привязывается к желанию и бот шлёт туда обновления.
