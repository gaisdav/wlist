# Этап 11. Real-time обновления

## Цель

Подключить Supabase Realtime для тех экранов, где задержка особенно заметна: открытое желание (новые комментарии, изменения слотов) и (опционально) лента. Сохранить fallback на refetch для остальных мест.

## Зависимости

- Этап 03 (слоты), 06 (комментарии), 05 (лента).

## Скоуп

### 1. Подключение Supabase Realtime

- Включить `Realtime` для нужных таблиц: `wish_slots`, `wish_comments`, `feed_events`.
- Настроить RLS-aware подписки — клиенту приходят только те изменения, которые он по RLS видит.

### 2. Где использовать

- **Экран желания:**
  - Подписка на изменения `wish_slots WHERE wish_id = X` → live-обновление счётчика и списка участников.
  - Подписка на изменения `wish_comments WHERE wish_id = X` → новые комментарии без рефреша.
- **Лента (опционально):**
  - Подписка на новые `feed_events` для `actor_id IN (followees)` → баннер «есть 3 новых обновления, обновить».
- **Карточка списка моих желаний** — без realtime, достаточно refetch при возврате.

### 3. Архитектура подписок в `packages/core`

- Абстракция `useRealtimeSubscription({ channel, filter, onInsert, onUpdate, onDelete })`.
- Возможность подменить транспорт (Supabase / mock) — нужно для тестов и для будущего веб/RN.
- Автоматическая отписка при unmount.
- Reconnect-стратегия с экспоненциальным бэкоффом.

### 4. Производительность и стоимость

- Лимиты соединений Supabase Realtime — оценить при текущем плане.
- Подписываться **только на открытом экране**, не глобально.
- Объединять подписки в один канал, где возможно.
- Пропускать события, не относящиеся к текущему viewport (например, изменения слотов соседних желаний в списке).

## Вне скоупа

- Realtime для уведомлений в самом UI (бэйдж «1 непрочитанное») — отдельная фича, может быть реализована позже.
- Серверный push в фоновом режиме (TMA не работает в фоне).
- Конфликт-резолюция / OT / CRDT — у нас не collaborative editor.

## Ключевые решения

- **Realtime — только там, где задержка реально мешает UX.** Везде остальное — пассивный refetch.
- **Опираемся на RLS** — Supabase Realtime их применяет. Любая подписка автоматически безопасна.
- **Стратегия «pull on focus»** — даже без realtime invalidate-им queries при возврате на вкладку/в TMA.

## Definition of Done

- При открытом экране желания изменения слотов и комментариев появляются без F5.
- Закрыл экран — подписка корректно отвалилась.
- Reconnect восстанавливает подписку.
- Под нагрузкой не падает.
